## Working architecture (end of day)

```
amispoof http://localhost:8791    ── node server.mjs (sets COOP/COEP)
     │
     ├── imports onnxruntime-web from ./vendor/onnxruntime-web/      (LOCAL, no CDN)
     ├── imports @mediapipe/tasks-vision from ./vendor/mediapipe-…/  (LOCAL)
     ├── loads ./models/minifasnet_v2.onnx                            (LOCAL)
     └── loads ./models/face_landmarker.task                          (LOCAL)
     
     SpoofDetector with toggles:
       enableMoire: <set true at runtime if camera is HD+>
       enableTemporal / Flicker / Tremor / Expr / BgGrid: false (AUC ≤ 0.55 in-house)
       ortExecutionProviders: ["wasm"]                                (WebGPU dropped, multi-threaded WASM via COOP/COEP)
       heavyAnalyzerFrameSkip: 5
       MiniFASNet weight: 3.0 (was 5.0 → caused REPLAY-as-LIVE; 1.5 → too low for LIVE)
       
     SessionEngine.checkTextureCollapseReplay (V3):
       ≥30 % of last 30 frames with texture_score < 25
       AND median skin_score in window ≥ 30
       → VIDEO_REPLAY incident (HIGH severity, throttled 2.5 s)
       3 incidents → incident_override → verdict flips to SPOOF
     
     SessionEngine isLive:
       baseLive = adjustedReal > 0.45 AND proverLive AND no_incident_override
       isLive = baseLive AND (qualityOk OR (proof_proven_live AND zero_incidents AND ≥1 blink))
```

## What we know about discrimination on YOUR setup

From 33 frame-logged JSONs (6 LIVE + 8 SPOOF sessions, ~23 k frames):

**Top top-line analyzer AUCs (cross-session):**
- texture: 0.836 — primary discriminator at top-line
- background_motion: 0.779
- pose_3d_consistency: 0.751 (partly distance-confounded)
- eyebrow_motion: 0.742
- landmark_variance: 0.742
- gaze: 0.733
- blink: 0.715
- screen_replay: 0.683
- minifasnet: 0.645 — barely discriminates at top-line

**Sub-features that catch what top-line misses:**
- texture.texture_score: AUC 0.92 — the veto's primary signal (collapses 100 → 16 on SPOOF)
- screen_replay.skin_score: AUC 0.89 — the veto's co-signal (catches twilight LIVE vs REPLAY)

**Per-session means cleanly separate (small dataset, validate on more subjects):**
- moire.std_mean: LIVE 1207 ± 6 / SPOOF 1224 + (clean gap, possible discriminator)
- screen_replay.skin_score: LIVE max 27.8 / SPOOF min 31.9 (clean gap)
