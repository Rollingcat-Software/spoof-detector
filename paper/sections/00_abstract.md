# Abstract

*Marmara University CSE4297 / CSE4298 capstone project (2025–2026); advisor: Doç. Dr. Mustafa Ağaoğlu. Open-source `spoof-detector` engine extracted from the broader FIVUCSAS biometric-identity SaaS.*

> **Status (2026-11-01): working draft, superseded for publication.** The verified passive-PAD findings below are being re-reported in the FIVUCSAS Biometric Puzzle paper. This abstract was corrected so that the headline numbers are attributed to the pipeline that produced them.

Face anti-spoofing (FAS) literature is dominated by per-frame classification, yet deployment contexts such as proctoring, hosted KYC and identity verification operate at session level. We present **`spoof-detector`**, an open-source presentation-attack-detection engine that combines a per-frame MiniFASNet ONNX discriminator (the pretrained UniFace model, used without retraining) with twelve auxiliary image and temporal analyzers under a heuristic multi-class fusion, plus a peak-sensitive mean-plus-worst-decile session verdict. We evaluate zero-shot on CASIA-FASD (N = 2 408) and CelebA-Spoof (N = 2 611), both obtained from unofficial HuggingFace mirrors, reporting ISO/IEC 30107-3 APCER / BPCER / ACER and AUC with stratified bootstrap 95 % confidence intervals. The main finding is negative: the MiniFASNet-only pipeline (AUC 0.945 [0.937, 0.956] on CASIA-FASD, 0.782 [0.766, 0.799] on CelebA-Spoof) is significantly better than the fused pipeline (AUC 0.914 [0.901, 0.935] and 0.725 [0.705, 0.748]); the confidence intervals do not overlap on either dataset. On still images the multi-frame analyzers cannot fire, so these results do not test the session verdict, whose resistance to spoof-burst dilution remains unmeasured. The production deliverable is a client-side TypeScript bundle (≈ 173 kB) running on WebAssembly via `onnxruntime-web` and MediaPipe Tasks, live at `https://amispoof.fivucsas.com/`, together with an MIT-licensed Python reference and benchmark harness.
