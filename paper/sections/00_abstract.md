# Abstract

*Marmara University CSE4297 / CSE4298 capstone project (2025–2026); advisor: Doç. Dr. Mustafa Ağaoğlu. Open-source `spoof-detector` engine extracted from the broader FIVUCSAS biometric-identity SaaS.*

Face anti-spoofing (FAS) literature is dominated by per-frame classification, yet the deployment contexts that drive face-liveness demand — proctoring, hosted KYC, identity verification — operate at session level, where an attacker can hold a screen-replay or printed photograph for minutes and dilute the mean verdict by briefly revealing a real face. We present **`spoof-detector`**, a session-based hybrid presentation-attack-detection engine combining a per-frame MiniFASNet ONNX discriminator with twelve auxiliary temporal and image analyzers under calibrated multi-class fusion and a peak-sensitive 50 / 50 mean-plus-worst-decile session verdict that resists spoof-burst dilution; a fifteen-axis passive liveness-proof scorer tracks "is this user still live?" continuously without active challenges. We evaluate zero-shot on CASIA-FASD (N = 2 408) and CelebA-Spoof (N = 2 611) via HuggingFace mirrors plus an in-house replay sub-protocol (N = 100), reporting ISO / IEC 30107-3 APCER / BPCER / ACER and AUC with stratified bootstrap 95 % confidence intervals: AUC 0.945 [0.937, 0.956] on CASIA-FASD and 0.782 [0.767, 0.799] on CelebA-Spoof, the two CIs strictly separated at 95 %; ablations show that calibrated weighting improves fused AUC by +0.023 over uniform weighting on the in-house replay sub-protocol (uniform 0.919 → calibrated 0.942, N=83), with re-weighting texture / moire — which we measure to be anti-correlated with liveness on modern high-resolution capture — recovering ≈65 % of that gain on its own (§8.3), and that two in-house-calibrated analyzers (device-boundary, micro-tremor) *harm* zero-shot generalization (Δ −0.027 and −0.021 AUC respectively, measured in §8.2), motivating per-operator recalibration. The production deliverable is a client-side TypeScript browser bundle (≈ 173 kB) running entirely on WebAssembly via `onnxruntime-web` (with optional WebGPU) and MediaPipe Tasks — no GPU server and no frame uploads. An iBeta PAD-Level-1 submission package, MIT-licensed Python reference and benchmark harness accompany the release at `https://amispoof.fivucsas.com/`.
