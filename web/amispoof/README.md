# amispoof — browser anti-spoof tester

Self-contained static bundle of the FIVUCSAS spoof-detector pipeline,
intended for deployment at `fivucsas.com/amispoof/`. Runs entirely
client-side; no server GPU, no frames uploaded.

## What's here

Source (checked in):

- `index.html` — page layout + importmap (resolves `onnxruntime-web` and
  `@mediapipe/tasks-vision` to jsdelivr CDN).
- `app.js` — driver: webcam loop, UI updates, session report download.

Derived (regenerated by `npm run amispoof:bundle` — gitignored):

- `lib/spoof-detector.js` — copy of the built ESM bundle from `../dist/`.
- `models/minifasnet_v2.onnx` — copy of `../public/models/minifasnet_v2.onnx`
  (1.7 MB).
- `models/face_landmarker.task` — copy of `../public/models/face_landmarker.task`
  (3.7 MB).

## Build + smoke-test locally

```bash
cd /opt/projects/fivucsas/spoof-detector/web
npm install
npm run build
npm run amispoof:bundle
npm run amispoof:serve      # opens on http://127.0.0.1:8791/
```

The page needs `https://` for `navigator.mediaDevices.getUserMedia` —
`localhost` is allowlisted by browsers so the local serve works.

## Deploy to fivucsas.com/amispoof/

The fivucsas.com root is served by Hostinger. Deploy via SCP:

```bash
cd /opt/projects/fivucsas/spoof-detector/web
npm run build && npm run amispoof:bundle
scp -P 65002 -r amispoof/* \
  u349700627@46.202.158.52:~/domains/fivucsas.com/public_html/amispoof/
```

## Cache headers (Hostinger .htaccess)

Drop this `.htaccess` into `~/domains/fivucsas.com/public_html/amispoof/`
so the models and lib bundle cache aggressively:

```apache
<IfModule mod_headers.c>
  <FilesMatch "\.(onnx|task)$">
    Header set Cache-Control "public, max-age=31536000, immutable"
  </FilesMatch>
  <FilesMatch "\.(js|css)$">
    Header set Cache-Control "public, max-age=604800"
  </FilesMatch>
  Header always set X-Robots-Tag "noindex, nofollow"
</IfModule>
```

## Runtime dependencies (loaded from CDN)

| Package | Resolved by | Used for |
|---|---|---|
| `onnxruntime-web@1.18.0` | jsdelivr (importmap + `wasmPaths`) | MiniFASNet inference (WASM EP, CPU) |
| `@mediapipe/tasks-vision@0.10.18` | jsdelivr (importmap + `wasmBaseUrl`) | FaceLandmarker 478-pt mesh |

Both are aggressively cacheable via jsdelivr's `Cache-Control: public, max-age=31536000, immutable`.

## What it shows

- **Verdict** (LIVE / SPOOF) with confidence percentage and peak-sensitive
  session memory — one sustained spoof burst flips and keeps the verdict.
- **Six analyzers** with live score 0–100: MiniFASNet (w 5.0), Screen
  Flicker (3.0), Device Boundary (2.5), Micro-Tremor (2.5), Landmark
  Variance (2.0), Blink (0.5). Together ~95% of the fuser's weight mass.
- **Per-category P(spoof)** for the 7-class taxonomy: static_image,
  video_replay, mask_3d, heavy_makeup, ar_filter, deepfake_injection.
- **Session counters**: frames, FPS, duration, faces detected, blink
  count, incidents.
- **Incident ledger** — running list of detected anomalies with timestamp.
- **Download session report** — JSON snapshot of the verdict for sharing
  in bug reports or paper appendices.
